# DrJulio — Sistema Médico

Sistema médico criado do zero no repositório `juliodelgadogui-collab/Drjulio`.

Arquitetura inicial: PHP 8+ + SQLite, módulo isolado em `/medical`, autenticação segura, prontuário, pacientes, atendimentos, documentos, CID-10, modelos, assinatura/validação e IA assistiva. O sistema será desenvolvido por etapas sem depender do MusicRoad-AI.
